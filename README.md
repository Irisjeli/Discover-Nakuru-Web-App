# Discover Nakuru | Interactive GIS Web Map

An interactive web map showcasing places, attractions, landscapes, heritage sites, accommodation, restaurants, and other points of interest across **Nakuru County, Kenya**.

## About

Discover Nakuru was developed as a GIS portfolio project to make Nakuru's places and geographic information easier to explore through an interactive web map.

## Methods & Techniques

* **GIS & Spatial Analysis** - mapping and spatial filtering of places within Nakuru County.
* **OpenStreetMap & Overpass API** - free discovery of geographic features and place information.
* **County Boundary Clipping** - restricting mapped features to the Nakuru County boundary.
* **GeoJSON** - storing and serving spatial data to the web map.
* **Leaflet.js** - interactive mapping, markers, popups, search and filtering.
* **HTML, CSS & JavaScript** - web map interface and functionality.
* **Local Storage** - allowing users to add places and photographs locally.

## Data Sources

* OpenStreetMap contributors
* Nakuru County boundary data
* Additional photographs and information from credited sources
